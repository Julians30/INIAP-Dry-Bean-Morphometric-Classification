# Tables

This directory contains machine-readable derived summaries supporting the manuscript.

## Analysis summaries

The `analysis_summaries/` folder includes the principal benchmark and redundancy summaries, including:

- baseline and hybrid model summaries;
- deep tabular model summary;
- FULL_11 model ranking;
- primary FULL_11 versus REDUCED_7 ablation summary;
- STRICT_6 sensitivity summary.

## Supplementary tables

The `supplementary/` folder mirrors the supplementary analyses cited in the manuscript:

- S1 descriptive morphometry;
- S2 Kruskal-Wallis/Holm/effect-size analysis;
- S3 STRICT_6 fold-level results;
- S4 strict calibration metrics by seed;
- S5 high-confidence and class-conditional calibration diagnostics;
- S6 selective-prediction counts and rejected-set composition;
- S7 equivalence and ROPE sensitivity analyses;
- S8 MCC and Cohen's kappa supporting results.

These files contain derived analysis outputs only and do not redistribute the original morphometric observations.
