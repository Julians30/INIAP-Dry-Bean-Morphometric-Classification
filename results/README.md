# Results

This directory contains selected **derived outputs** required to audit the reported analyses.

The repository does not redistribute the original morphometric observations. Large intermediate artifacts and local checkpoints are not committed unless they are necessary to verify a reported result.

Planned public result groups include:

- fold-level performance metrics;
- redundancy-ablation summaries;
- calibration summaries;
- selective-classification summaries;
- statistical-comparison outputs;
- final learning-curve summaries.
