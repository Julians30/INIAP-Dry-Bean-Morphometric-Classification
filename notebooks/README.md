# Notebooks

This directory contains the audited notebooks used to support the manuscript workflow.

Notebook outputs, authentication tokens, personal Colab metadata, temporary files, and obsolete local copies are excluded from the public versions.

## Important supersession note

`NB15_Calibration_Gap_Figure_Publication.ipynb` generated an earlier fixed-width calibration visualization. It is not used for the final manuscript because the final calibration evidence is generated by NB16 using internal OOF probabilities created exclusively within each outer-training partition.
