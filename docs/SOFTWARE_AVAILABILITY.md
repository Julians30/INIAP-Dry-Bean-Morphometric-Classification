# Software Availability

The computational materials supporting the manuscript are publicly available in this repository:

**Repository:** https://github.com/Julians30/INIAP-Dry-Bean-Morphometric-Classification

**License:** MIT License

Public materials include:

- audited analysis notebooks;
- validation and modeling configuration;
- selected derived model-performance outputs;
- statistical-test outputs;
- calibration and selective-prediction summaries;
- final publication figures;
- machine-readable analysis summaries;
- reproducibility and environment documentation.

The original morphometric dataset, raw grain photographs, raw acquisition metadata, private TabPFN credentials, and pretrained checkpoint files are not distributed through the repository.
